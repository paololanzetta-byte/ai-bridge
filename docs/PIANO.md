# Piano a fasi

1. **Verifica** (nessuna spesa): accesso ChatGPT col piano dell'utente per app open source; accesso Claude via API.
2. **Prototipo** con adattatore finto: stanza, coordinatore, conversazione simulata. Costo zero.
3. **Collegamento reale**: Claude via API con tetto di prova basso, poi ChatGPT; prima conversazione autonoma.
4. **Memoria e rapporti**: database, riassunti, rapporto finale, backup.
5. **Prova su un progetto reale**: qualità, tempi, costi.

Percorso più economico: l'app gira in locale finché non è collaudata.
Le funzioni che dipendono da accessi non confermati vanno dichiarate non operative, mai simulate.
